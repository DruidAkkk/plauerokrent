**Цель:** найти новые идеи и функции для проекта, изучая конкурентов и боли продавцов на Playerok и FunPay.
**Режим:** автономное исследование (пока владелец спит). Отчёт растёт с каждой итерацией.
**Начато:** 2026-10-15.

> Ниже — не только «что у конкурентов», но и приоритизированный бэклог идей с обоснованием.
> Легенда сложности: 🟢 быстро (дни) · 🟡 средне (неделя) · 🔴 крупно (недели).

## 2. Конкуренты и их функции (матрица)

### FunPay Cardinal (open-source, sidor0912) + экосистема плагинов
Ядро: автовыдача (2 типа — одинаковый товар / чередующиеся ключи-аккаунты, с удалением выданного из
хранилища), **автоподнятие лотов**, автоответ на команды, **авто-восстановление лотов после продажи**,
**авто-деактивация при нулевом остатке**, вечный онлайн, Telegram-уведомления (несколько чатов),
**авто-вывод средств**, локализации (en/uk).
Плагины сообщества: Chat Sync (чаты FunPay ↔ Telegram-форум), Review Chat Reply (ответ после отзыва),
Advanced Profile Stats (статистика продаж/дохода), Status Plugin, **авто-сдача Steam-аккаунтов в аренду**,
**авто-продажа Steam-поинтов**, **авто-понижение цен по рынку (репрайсер)**, авто-тикеты в поддержку,
**монитор позиций лота** (алерт если лот упал/пропал из выдачи), **ИИ-автоответчик** (OpenAI-совместимый),
Auto Send (сообщения по расписанию), Lot Manager (массовое удаление лотов).

### FunPay Pulse (платный, funpaypulse.com)
Десктоп-приложение (Win/macOS) + активация через Telegram + **VPS-воркер для 24/7** (на ПК Pulse
останавливается — нужен VPS). В одном окне: несколько аккаунтов, редактирование лотов, проверка цен,
баланс/продажи, **журнал действий («что именно сделал плагин»)**, открыть заказ → ответить/изменить лот
без переключения между аккаунтами в браузере. Плагины (~15 бесплатных): авто-ответчик, AutoTicket
(тикеты в поддержку), выдача товаров, аренда аккаунтов. → **наша модель 1-в-1** (десктоп + VPS-воркер
+ плагины), подтверждает выбранную архитектуру.

### Прочие конкуренты (FunPay)
- **FunPayCortex** (Beedgee): автовыдача, плагины, **статистика, прокси, мульти-админ**, готовое FunPay API.
- **funpule** (yrybacode): умное автоподнятие, автовыдача, темы/обои (кастомизация UI).
- **FunPay Tools**: **Android-приложение** + Chrome-расширение — автоподнятие и **демпер цен** на телефоне.
- **FunPay Hub** (fphub.ru), **FunPayPanel**: панели-магазины плагинов (экосистема/монетизация плагинов).

### Боты/инструменты Playerok
Неофиц. Python-клиент + Telegram-панель (уведомления, ответы покупателям, автовыдача, автоподтверждение
сделок, выставление/поднятие/восстановление лотов; вход по email-коду без cookie). Браузерное расширение
**Playerok Helper** (поднятие товаров из списка, канбан заготовленных ответов, **чёрный список покупателей**,
push-уведомления). Коммерческие: PLAYEROK PREMIUM, PlayerOK Manager (автовыдача, автоподтверждение,
аналитика заказов, автоподнятие, автоответы в Telegram).

## 3. Боли продавцов (из отзывов) → возможности
1. **Слабая защита продавца в спорах** — нет удобного способа приложить доказательства выдачи; поддержка
   часто на стороне покупателя, деньги возвращают без запроса доказательств. → **огромная возможность** (см. идею #4).
2. **Задержки доставки сообщений** в чатах Playerok — продавец кажется «не в сети». Боты обходят лишь частично.
3. **Высокая комиссия** и **медленная поддержка** (ответ раз в сутки), блокировки «по кайфу».
4. **Нет официального API** — все решения неофициальные, ломаются при изменениях площадки.
5. Мало независимых отзывов о ботах — доверие низкое; выигрывает тот, у кого прозрачность/репутация.

## 4. Бэклог идей (приоритизированный)

### A. Высокий приоритет (уникально или прямой спрос)
- **#4 «Щит споров» / доказательства выдачи** 🟡 — автоматически логировать каждую выдачу: время, что
  выдано (маскированно), скрин/текст сообщения покупателю, факт входа арендатора. По сделке — экспорт PDF/«досье»
  для спора. Бьёт в главную боль Playerok (слабая защита продавца). Ни у кого толком нет. **Наш киллер-фич.**
- **#1 ИИ-автоответчик** 🟡 — подключение к OpenAI-совместимому API (в т.ч. локальному/дешёвому),
  отвечает на частые вопросы, статусы аренды, «как войти», ведёт до покупки. У Cardinal есть, у нас нет.
- **#2 Двусторонний Telegram-чат** 🟡 — сейчас Telegram у нас read-only; добавить ответ покупателю прямо
  из Telegram + зеркалирование чатов (как Cardinal Chat Sync). Продавец ведёт всё с телефона.
- **#3 Монитор позиций лота** 🟢 — следить за местом лота в выдаче Playerok (каталог у нас уже парсится
  для репрайсера!), алерт в Telegram если упал/пропал → подсказать поднять/сменить цену.

### B. Средний приоритет (есть спрос, укрепляет продукт)
- **#5 Жизненный цикл лота** 🟢 — авто-деактивация при пустом пуле (частично есть), авто-восстановление/
  публикация при появлении стока, авто-поднятие по расписанию (бесплатный буст — у нас есть bump_item).
- **#8 Расширенная аналитика** 🟡 — дашборд: LTV покупателя, топ-игры по доходу, конверсия чат→покупка,
  доход по плагинам, лучшие часы продаж. Частично есть, усилить до «Advanced Profile Stats».
- **#6 Планировщик/рассылка** 🟢 — сообщения покупателям по расписанию (напоминания, акции,回покупка).
- **#11 Канбан заготовленных ответов** 🟢 — быстрые шаблоны ответов (как Playerok Helper), вставка в чат.

### C. Стратегические (крупно)
- **#9 Мультиплощадка: + FunPay** 🔴 — добавить FunPay рядом с Playerok (адаптер по образцу playerok.py).
  Удваивает рынок; у нас уже чистая порт-архитектура (Marketplace-интерфейс). Самый большой рычаг роста.
- **#7 Авто-вывод средств** 🟡 — вывод баланса Playerok по правилам (порог/расписание).

### D. Нишевое
- **#10 Авто-продажа Steam-поинтов** 🟡 · **#12 обход задержки чатов** (умный приоритетный поллинг) 🟡.

### E. Добавлено в It.2 (из Pulse/Cortex/FunPay Tools)
- **#13 Журнал действий бота (feed)** 🟢 — как у Pulse: лента «что сделал бот/плагин» по-человечески
  (выдал X, кикнул Y, поднял лот Z) с фильтрами. У нас логи уже есть — оформить в понятную ленту на дашборде.
- **#14 Мульти-админ / роли** 🟡 — несколько операторов с правами (владелец/помощник), как Cortex. Для магазинов с наёмными саппортами.
- **#15 Менеджер прокси** 🟢 — пул прокси с проверкой здоровья, привязка к аккаунтам/плагинам (поля прокси уже есть, добавить управление/ротацию/чек).
- **#16 Магазин/хаб плагинов** 🔴 — экосистема как у Cardinal/Pulse: включать доп-плагины, часть платные
  (прямая монетизация, совпадает с бизнес-моделью «база бесплатно, плагины платно»).
- **#17 Мобильный компаньон** 🟡 — Telegram mini-app или лёгкое мобильное управление (FunPay Tools — Android).
  У нас уже есть Telegram-бот — расширить до полноценного управления с телефона (пересекается с #2).
- **#18 Кастомизация интерфейса** 🟢 — темы/акценты (funpule делает темы/обои). Дёшево, повышает «премиальность».

> **Рамки исследования:** собираю только легальные функции (автоматизация, аналитика, чат, защита в спорах,
> UX, монетизация). НЕ рассматриваю «антидетект / обход банов / сокрытие передачи аккаунтов» — это обход
> правил площадок и путь к банам/претензиям.
